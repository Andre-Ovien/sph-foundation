# SPH Foundation

The public website for SPH Foundation, built with Astro and TypeScript.

## Development

```sh
npm install
npm run dev
```

The current implementation includes the responsive homepage, housing-program presentation,
visitor pathways, FAQs, partnership callout, newsletter signup, and contact/get-started forms.

The forms currently provide the finished frontend experience only. Delivery and automated
receipts will be connected through a server-side email integration before public submissions
are enabled.
